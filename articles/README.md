# 加文章：不用改 HTML

文章都放在这个 `articles/` 文件夹里，一篇一个 JSON 文件。
页面打开时会自动发现这里的 JSON 文件，不用改 `reading.html`。

## 加一篇新文章（3 步）

1. 复制 `_template.json`，改名成新文章的 id，比如 `my-trip.json`
   （文件名用英文小写字母、数字和 `-`，不要用中文和空格）。
2. 按模板填内容（字段说明见下），保存。
3. 推到 GitHub 的 main 分支，再去 Abasthan 后台点一次 Manual Deploy，
   打开阅读页就能看到新文章了。

## 字段说明

- `id`：文章的唯一编号，和文件名一致，比如 `my-trip`。
- `title`：英文标题，显示在首页卡片上。
- `cat`：分类，比如 `科技` / `旅行` / `自然` / `健康` / `环境` / `故事`。
- `level`：难度，只能填 `B1`、`B2`、`C1` 其中一个。
- `minutes`：大概要读几分钟，填数字。
- `desc`：一句话介绍，显示在首页卡片上。
- `vocab`：重点词，一个词一个对象：
  - `w`：英文词（这个词必须在正文里出现过）
  - `ph`：音标，比如 `/ɪɡˈzɑːmpl/`
  - `pos`：词性，比如 `n.` / `v.` / `adj.`
  - `zh`：中文意思
  - `en`：英文解释（简单一点）
  - `ex`：英文例句，`exZh`：例句的中文翻译
- `paras`：段落，一段一个对象：
  - `en`：英文句子列表，一句一个
  - `zh`：中文译句列表，**数量必须和 `en` 一一对应**，第几句对第几句

## 注意

- 每段的英文句数和中文句数必须一样多，否则点句高亮会对不上。
- 重点词要在正文里出现，第一次出现的地方就是同步滚动的锚点。
- `_template.json` 和 `index.json` 不会被当成文章（`index.json` 只是备用列表，
  万一 GitHub 文件列表那一刻打不开，页面就用它来找文章）。
